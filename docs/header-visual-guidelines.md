# Header 视觉规范

> 用于协同设计、开发与验收，以下规范覆盖桌面与移动端。

## 布局间距
- **整体高度**：未滚动时主导航区 `88px`（含上下 `24px` 内边距），滚动压缩至 `64px`（上下 `16px` 内边距）。
- **内容容器**：桌面端最大宽度 `1120px`，左右内边距 `16px`。
- **导航项间距**：一级导航水平方向间距 `12px`，Mega Menu 列间距 `24px`，列内项目垂直间距 `8px`。
- **操作区**：右侧图标按钮尺寸 `48px` × `48px`（含 40px 有效点击区）。

## 字号与字重
- **顶栏**：`14px`，`500` 字重。
- **一级导航**：`14px`，`500` 字重，字距 `0.02em`。
- **列标题**：`12px`，大写，`600` 字重。
- **链接正文**：`14px`，`600` 字重；描述文字 `12px`，`400` 字重。

## 响应式断点
- **桌面布局**：`≥ 1024px` 使用横向导航与 Mega Menu。
- **移动布局**：`< 1024px` 自动切换为抽屉式导航，保留搜索快捷按钮。
- **内容栅格**：Mega Menu 在 `≥ 768px` 呈现两列内容 + 一列精选位。

## 状态层级
- **Hover**：背景色 `#F8FAFC`，文字 `#0F172A`，图标轻微放大 `1.05x`。
- **Active/Focus**：描边 `2px` `#94A3B8`，保留圆角 `12px`，遵循 WCAG 对比度。
- **Sticky**：滚动超过 `32px` 后切换为增强阴影 `themeTokens.shadows.sticky`，背景透明度提高至 0.95。
- **Disabled**：暂未使用，如需可统一降低透明度至 `60%`。

## 触控反馈
- 移动端抽屉覆盖全屏高度，背景蒙层透明度 `40%` 并带模糊。
- 抽屉内链接与按钮最小高度 `44px`，左对齐显示。
